## Usage

```bash
npx create-stack54 [project-name] --template [template]
```

For example:

```bash
npx create-stack54 my-app --template express
```

`--t` is a short alias for `--template`. If you omit the project name or template, the CLI prompts for them; template choices are fetched from the Stack54 repository.

After scaffolding, follow the generated project's README. See the [Stack54 quick start](../../docs/getting-started.md) for the current workflow.
